# 人味化改写记录

执行日期：2026-08-25。按 `anti-ai-checklist.md` 的 9 项要求逐段审校。

## 分段复核

1. 开头问答段：原文“答案很短” → 保留。它直接回答读者问题，没有宏观铺垫。
2. 分组误解段：原文“问题也恰恰出在这个‘第 1 组’上” → 改为“麻烦在于这个‘第 1 组’”，并用分号拆开两种误解，减少模板腔。
3. IARC 定义段：原文 → 保留。首次出现机构名称与“危害识别”定义，信息不可删。
4. 危害与风险段：原文 → 保留。明确区分 hazard 与 risk，是全文核心证据边界。
5. 刀具类比段：原文 → 保留，并保留“类比不能替代实际暴露判断”的限定。
6. 分类总览段：原文 → 保留。直接纠正“三类”说法，说明 2A/2B。
7. 四组定义列表：原文 → 保留。长短不强行统一，避免牺牲方法学准确性。
8. 分类数量段：原文 → 保留。补有页面更新时间与数据会变化的提示。
9. agent 范围段：原文“把这些项目放进同一组，是按证据结论归档” → 改为“因为证据结论相近”，并把“从强到弱的毒性榜单”改为“毒性榜单上并列名次”。
10. 甲醛证据来源段：原文 → 保留。没有虚构病例或个人经历。
11. 癌症部位结论段：原文 → 保留。部位与证据等级均可追溯至 IARC 报告。
12. 证据边界提示段：原文“这里需要加两道边界” → 改为“读这条结论时要守住两道边界”，与前文连接更自然。
13. 第一条边界：原文“第一，道理上不能从……” → 删除教科书式序号，改为直接判断。
14. 第二条边界：原文“第二，建立致癌因果关系……” → 改为“另一道边界在暴露场景”，把转折落在具体对象上。
15. 重评说明段：原文 → 保留。区分未来重评建议、当前分组与新观察，避免过度推断。
16. 气味问答段：原文 → 保留。短句承担明确判断，随后解释个体差异。
17. 国内标准段：原文 → 保留。数值、平均时间与标准来源齐全。
18. 数值比较段：原文 → 保留。提醒检测方法与适用目的，防止错误横比。
19. 家庭控制引入段：原文 → 保留。行动建议与证据结论衔接自然。
20. 家庭四步列表：原文 → 保留。每步给出对象、动作和限制，不承诺固定通风天数。
21. 职业控制段：原文“职业场景的逻辑不同” → 改为“到了职业场景，控制重点会变”，并限定呼吸防护需经评估选择。
22. 结论与三句提示：原文 → 保留。没有口号式升华，重申群体证据与个体风险的边界。
23. 参考来源：原文 → 保留。六项关键来源均可追溯。

## 9 项清单结果

- 句长有明显变化，短句用于判断，长句保留必要限定。
- 未使用“首先、其次、综上所述”等模板句。
- 未命中营销高频词。
- 开篇直接回答具体问题。
- `real_experience_sources` 为空，正文无具体第一人称经历。
- 具体分类、日期、标准值和癌症部位均有来源。
- 标点服务语义，没有为检测分数机械插入符号。
- 六个小节长短不完全对称，结构跟随问题推进。
- 符合“普癌新声”专业、克制、易懂、可核查的医学科普边界。

## 第二轮：加入“甲醛白菜”新闻后的逐段复核

1. 分享摘要：原文仅回答甲醛分组 → 改为“违法行为已获官方初步确认 + 不能直接推出吃一口就患癌”，把新闻事实和医学边界同时放在第一屏。
2. 8 月 22 日通报段：新闻素材 → 改写为县政府已确认的主体、行为、处置和“仍在侦办”状态；删除自媒体未获官方确认的数量与浓度。
3. 8 月 23 日处置段：官方原文 → 压缩为“指导属地调查、追查流向、专项抽检”，不添加处置结果。
4. 8 月 25 日抽检段：抽检通报 → 保留 69 家、284 批快检、17 批法检及截止时间；明确只指当时公布的样品。
5. “两种结果是否矛盾”段：原文容易被写成争辩 → 改为按对象、批次、时间和方法解释，并保留“案件仍未结束”。
6. 新闻中的三个问题列表：原始素材混合违法、检测和致癌 → 拆成三个可分别回答的问题，防止结论互相替代。
7. 新闻与 IARC 过渡段：原文 → 保留短判断“食品安全违法行为应被追查处置”，随后把医学判断落到途径、浓度和时间。
8. 第 1 组解释段：原文只谈家庭暴露 → 增加“不能把一次食用直接等同于鼻咽癌或白血病”的限定。
9. 食品内源与外源甲醛段：官方科普素材 → 改为“检出不必然证明违法添加，但内源性微量不能替外源添加开脱”，避免两个方向的误读。
10. 消费者建议段：原始建议易滑向“如何把可疑白菜洗干净” → 改为停止食用、留存信息并反映，不承诺冲洗、浸泡或烹煮可以补救。
11. 既有 IARC 分组、职业证据、室内标准与控制段：原文 → 保留；第一轮逐段记录继续有效，事实结论未因热点改写而改变。
12. 参考来源段：6 项 → 扩充为 10 项，新增县政府通报、三部门处置、宿迁抽检与农业农村部科普。

第二轮仍无具体第一人称经历；没有把个案扩写成市场普遍现象，也没有把阶段性合格结果解释为案件失实。

## 第三轮：降低工整感

1. 摘要：原文“但这两句话拼在一起……” → 改成“可是，这不等于……中间还差了暴露剂量、途径和时间”，让判断先落地，再补条件。
2. 新闻时间线：原文连续三个相似长句 → 第三段改为“两天后”起句，并用分号保留抽检口径。
3. 抽检解释：原文一段完成正反论证 → 改成“乍看之下，两边像是在打架。其实不是。”短判断后另起证据段。
4. 三问列表：原文三条项目符号 → 改为连续追问和短回答，减少“标准答案”版式。
5. 过渡句：原文“三问不能互相替代” → 改为“三道题，各有各的证据。混着回答，结论就容易跑偏。”
6. Group 1 误解：原文“两种理解都不准确” → 改为“方向都错了”，句子更短，但不口语表演。
7. 危害与风险定义：原文单个长句 → 拆成两个具体问题，保留方法学含义。
8. 类比段：删除通用“刀具”类比 → 改用病理实验室福尔马林与偶然食品接触两个真实暴露场景。
9. 四组定义：原文四条句式高度一致 → 保留专业标签，缩短 2A，补足 2B 与 3 的自然解释。
10. 分类数量：原文数据和提示挤在一个长句 → 分成名单更新、当前数量、查表建议三个节奏。
11. 甲醛证据开头：原文“并非来自……而是综合……” → 拆为两句，避免模板对举。
12. 证据边界：原文“两道边界”结构 → 改为癌症部位与暴露场景各自自然展开。
13. 重评说明：原文连续双重否定 → 加入“注意，是建议重评”短句，明确当前状态。
14. 气味小节：标题“闻到味道，能判断甲醛超标吗” → 改成“鼻子不是检测仪”；正文用“发一张合格证”替代抽象表述。
15. 食品检测段：原文概念一次讲完 → 拆成气味、内源性、违法外源添加三层，最后一句单独作判断。
16. 行动建议标题：删除“与其……不如……”模板 → 改为“真正有用的，是把暴露降下来”。
17. 结尾：删除“三句话”列表 → 改成连续追问浓度、时间、途径与样品，把边界留在读者真正要判断的场景里。

第三轮脚本结果：AI 味从 21.8 降至 15.9；无模板短语、无营销高频词、无结构命中。
