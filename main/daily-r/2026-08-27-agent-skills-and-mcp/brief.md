# 研究问题

Agent Skills 与 MCP 都在扩展 AI Agent 的能力，但二者分别解决什么问题？怎样把稳定的专业流程写进 Skill，再通过 MCP 连接 PubMed、Zotero、数据库或其他外部工具，并保留权限、核验与人工确认边界？

# 写作要求

从 `SKILL.md` 指令片段与 MCP `tools/list` 返回的工具清单切入。解释 Agent Skills 的目录结构、渐进加载与可复用工作流；解释 MCP 的 tools/resources/prompts 与客户端—服务器关系；用医学文献检索和肿瘤登记质控示例展示组合方式。提供最小 Skill 示例、工具契约示例、选型表、常见误区与安全清单。明确两者互补而非替代，也不把安装第三方 Skill 或 MCP server 写成默认安全。
