# 研究问题

怎样把 AI 写作中的文献引用从“凭语言模型记忆生成”，改造成“通过 PubMed MCP 检索新文献，或通过 Zotero MCP 引用本机已有文献”的可追溯流程？两条路径分别适合什么任务，为什么仍不能省略人工核验？

# 写作要求

先提出 AI 撰写文章时可能生成不存在、错配或不支持正文的参考文献；再引出 PubMed MCP 与 Zotero MCP 两条路径。解释 ESearch、EFetch、Zotero Local API 与 MCP 的分工；提供可复制命令、输出预期、结构化提示词和四级核验清单。明确工具能显著降低捏造风险，但不能保证元数据、研究质量和结论适用性；社区 MCP 不等于 NCBI 或 Zotero 官方产品。只写可追溯事实，不虚构个人使用经历。
